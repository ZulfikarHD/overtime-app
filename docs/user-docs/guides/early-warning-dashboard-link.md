# Early Warning Link on the Dashboard - User Guide

## What is it?

The **Early Warning** chart on the **Dashboard** shows how much of the daily overtime budget your department or section used each day. The **Open Early Warning** button in the chart header takes you straight to the **Early Warning** list, already showing the same department, section and days as the chart. Writing a follow-up is done there, not on the Dashboard.

## Who Can Use It?

| Role                | What happens                                              |
| ------------------- | --------------------------------------------------------- |
| **Administrator**   | Sees the button; the list shows the department you picked |
| **Manager**         | Sees the button; the list shows your own department       |
| **Team Leader**     | Sees the button; the list shows your own department       |
| **Operator / User** | No button and no access to Early Warning                  |

## How to Use

### Go from the chart to the alerts

1. Open **Dashboard** in the sidebar
2. Open the **Distribution & Trends** tab
3. (Optional) Pick a **Department**, **Section** or **Date** at the top of the Dashboard
4. In the **Early Warning: Daily Contribution Index** chart, click **Open Early Warning**
5. The **Early Warning** list opens with the same department, section and the days from the start of the month up to the selected date
6. Click an alert (or **Follow Up**) to read it and write the follow-up

> 💡 **Tip:** The address of the list contains your filters, so you can copy it and send it to a colleague.

## Frequently Asked Questions (FAQ)

**Q: The chart is green. Why is the button still there?**
A: So you can always confirm there is nothing to do. The list will say "No alerts in this period".

**Q: Where did the follow-up form on the Dashboard go?**
A: It now lives only in the **Early Warning** menu, on the page of each alert.

**Q: I do not see the button.**
A: Operators cannot use Early Warning. If you are a Manager, Team Leader or Administrator, open the **Distribution & Trends** tab; the button is in the chart header.

## Troubleshooting

| Issue                                          | Solution                                                                                           |
| ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| The list is empty but the chart shows red days | Widen the date range in the list; the link only covers the month up to the Dashboard date          |
| The list opens with the last 7 days            | The Dashboard date is in a future month, so no days are carried over; change the dates in the list |
| A message says the filters are invalid         | The default list is shown instead; pick the filters again                                          |
